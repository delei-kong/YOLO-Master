# 实验注册表

> 用途：追踪全部 Issue 的训练实验历程，作为后续写 GitHub Discussion 和项目申请书的数据源。
>
> 规则：每次训练启动前填一行（规划），训练结束后补充结果列。

## 字段说明

| 字段 | 说明 | 时机 |
|------|------|------|
| ID | `Issue编号-序号`，如 `6-1` | 启动前 |
| Issue | 对应 Issue 编号 | 启动前 |
| 日期 | 启动日期 | 启动前 |
| 数据集 | VisDrone / SKU-110K / ... | 启动前 |
| 模型 | v0.1-N / EsMoE-N / ... | 启动前 |
| 关键参数 | epochs, batch, imgsz, 特殊 flag | 启动前 |
| 完整命令 | CLI 命令 | 启动前 |
| 状态 | 🟡运行中 / ✅完成 / ❌失败 | 持续更新 |
| mAP50 | 最终验证 mAP50 | 结束后 |
| mAP50-95 | 最终验证 mAP50-95 | 结束后 |
| SwanLab URL | 训练曲线链接 | 结束后 |
| 备注 | 异常、心得、结论 | 结束后 |
